# [ 랩탑 개발팀 260917 1635 캔버스 레터박스 렌더링 및 좌표 파이프라인 정합성 고도화 계획서 ]

본 계획서는 외부 리뷰어의 좌표계 및 UI 렌더링 파이프라인에 대한 기술적 비판을 전면 수용하고, 임상 현장 체어사이드 UAT 시 발생할 수 있는 시각적 기하 왜곡(2:1 강제 늘림), 목업 데이터 오버레이 혼선, 치아 바운딩 박스 클램핑 정밀도를 근본적으로 개선하기 위한 구체적 실행 계획입니다.

---

## 1. 외부 리뷰어 지적 사항 기술적 타당성 검토

외부 리뷰어의 분석은 매우 정확하며, 랩탑 개발팀이 간과하고 있던 렌더링 계층의 구조적 결함을 짚었습니다:

1. [캔버스 2:1 강제 스트레치 왜곡]:
   - 현황: `PanoramaCanvasViewer.tsx`에서 캔버스를 고정 `1200x600`으로 할당하고 `drawImage(img, 0, 0, 1200, 600)`으로 강제 렌더링 중.
   - 문제점: 실제 파노라마 X-ray는 기기 및 환자에 따라 2872x1504(약 1.91:1), 1170x540(약 2.16:1) 등 종횡비가 다양함. 2:1로 강제 스트레치되면 영상과 BBox 모두 서로 맞춰져 있더라도 영상 자체가 상하/좌우로 찌그러져 임상의 육안에 "좌표가 튀거나 깨졌다"는 착시를 유발함.
   - 타당성: [100% 타당]. 원본 종횡비를 보존하는 정규 Letterbox(Aspect-ratio fit) 렌더링이 필수적임.

2. [API 실패 시 타 환자 Mock 데이터 덮어쓰기]:
   - 현황: `App.tsx`에서 `inferPanorama` 실패 시 catch 블록에서 `setReportData(mockFinalReport)`를 호출함.
   - 문제점: 사용자가 업로드한 파노라마 영상 위에 전혀 다른 환자의 목업 BBox가 렌더링되어 박스가 허공에 뜨는 치명적 혼선을 유발함.
   - 타당성: [100% 타당]. 실패 시 목업 폴백을 차단하고 빈 어노테이션 상태와 명확한 오류 배너를 띄워야 함.

3. [Dental_002 클램핑 영역 및 패치 마진]:
   - 현황: 15% 패딩 패치 경계(`px1, py1, px2, py2`)로 클램프되고 있어 치아 BBox 바깥의 잇몸뼈나 인접치 영역으로 박스가 침범할 수 있음.
   - 타당성: [100% 타당]. 치아 바운딩 박스(`tx1, ty1, tx2, ty2`)를 기준으로 안전 마진(치아 너비/높이의 5% 이내) 클램핑을 강화해야 함.

4. [Dental_014 대시보드 MOCK 표기 미흡]:
   - 현황: 게이트웨이 헬스체크는 MOCK인데 대시보드 카드는 녹색 `LOW`로 출력되어 실제 딥러닝 추론 결과인 것처럼 오인될 소지가 있음.
   - 타당성: [100% 타당]. 카드 타이틀 및 뱃지에 `(MOCK/Baseline)` 표기를 강제해야 함.

## 2. 4대 개선 실행 트랙 (Action Tracks)

### [Track 1] PanoramaCanvasViewer 원본 종횡비 보존 Letterbox 렌더링 구현
- 대상 파일: `Dental_015/src/components/PanoramaCanvasViewer.tsx`
- 핵심 구현 내용:
  1. 원본 이미지의 실제 너비(`naturalWidth`)와 높이(`naturalHeight`)를 기반으로 캔버스 내 최적 맞춤 크기(`drawWidth, drawHeight`) 및 중앙 정렬 오프셋(`offsetX, offsetY`)을 동적 계산.
  2. `drawImage(img, offsetX, offsetY, drawWidth, drawHeight)` 적용으로 영상 왜곡 원천 차단.
  3. 바운딩 박스(002, 012) 및 치조골 폴리곤(003), 정중선(Midline) 좌표 변환 시 오프셋과 유효 렌더링 크기를 반영:
     - `vx = offsetX + norm_x * drawWidth`
     - `vy = offsetY + norm_y * drawHeight`
     - `vw = norm_w * drawWidth`
     - `vh = norm_h * drawHeight`

### [Track 2] API 실패 시 Mock 오버레이 강제 폴백 차단 및 격리
- 대상 파일: `Dental_015/src/App.tsx`
- 핵심 구현 내용:
  1. `handleRunInference` 실패 시 `mockFinalReport`를 덮어씌우는 로직 폐기.
  2. API 실패 시 업로드된 이미지 상의 어노테이션을 초기화(`emptyFindings`)하고, 명확한 빨간색 에러 알림 배너 표출.
  3. 목업 데이터는 "데모 샘플 불러오기" 버튼을 사용자가 능동적으로 클릭했을 때만 샘플 이미지(`/sample_panorama.png`)와 함께 1:1로 결합되도록 제한.

### [Track 3] Dental_002 치아 경계 타이트 클램핑 및 ONNX 스케일 가드 강화
- 대상 파일: `Dental_Panoramic_Reader/core/interfaces/dental_002.py`
- 핵심 구현 내용:
  1. 기존 패치 경계(`px1, px2`) 대신 치아 원본 바운딩 박스(`tx1, ty1, tx2, ty2`)를 기준으로 최대 5% 완충 마진을 초과하지 않도록 타이트 클램핑 적용:
     - `margin_x = (tx2 - tx1) * 0.05`
     - `gx1 = max(tx1 - margin_x, min(tx2 + margin_x, px1 + rx1))`
  2. Ultralytics ONNX 추론 결과의 `rx, ry`가 원본 패치 너비/높이를 비정상 초과(예: 512 고정 해상도 미역투영 등)할 경우 경고 로그 출력 및 비율 자동 보정 가드 탑재.

### [Track 4] Dental_015 Clinical Dashboard 골다공증 MOCK 뱃지 명시
- 대상 파일: `Dental_015/src/App.tsx`
- 핵심 구현 내용:
  1. 대시보드 4개 카드 중 '골다공증 위험도 (014)' 카드의 수치 표기를 `LOW (MOCK)`으로 변경.
  2. 서브 텍스트에 `미연동 스크리닝 베이스라인` 안내 문구를 삽입하여 임상 UAT 시 전문의의 오해 원천 방어.
